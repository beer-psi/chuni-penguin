## botinfo

Shows information about the bot.

=== "Text command"

    `c>botinfo`

=== "Slash command"

    `/botinfo`

## invite

Invite this bot to your server!

=== "Text command"

    `c>invite`

=== "Slash command"

    `/invite`

## legal

Links to the bot's [privacy policy](../legal/privacy-policy.md) and
[terms of service](../legal/terms-of-service.md).

Satisfies Discord lawyers.

=== "Text command"

    `c>legal`

=== "Slash command"

    `/legal`

## ping

=== "Text command"

    `c>ping`

=== "Slash command"

    `/ping`

## prefix

Get or set the text command prefix for the current server. **Setting the prefix requires
the user to have the Manage Server permission.**

=== "Text command"

    `c>prefix [new_prefix]`

=== "Slash command"

    `/prefix [new_prefix:<new_prefix>]`

## source

Get a link to the bot's [source code](https://github.com/beer-psi/chuni-penguin).

=== "Text command"

    `c>source`

=== "Slash command"

    `/source`
