## 8ball

Ask the 8ball a question. It can only respond with yes or no. The question must end with
a question mark ("?").

=== "Text command"

    `c>8ball <question...>`

=== "Slash command"

    `/8ball question:<question>`

## ar

=== "Text command"

    `c>ar`

=== "Slash command"

    `/ar`
